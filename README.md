Weather Information Page 
A simple weather dashboard that displays:

🌤️ Weather Icon

🌡️ Temperature

☁️ Condition (e.g., Moderate Rain, Sunny)

💧 Humidity

🌬️ Wind Speed

This project fetches weather data (e.g., from OpenWeatherMap API) and displays real-time weather info in a clean UI. Uses modern JavaScript and DOM manipulation.
